# 0.11.0

_2026-10-20._ The selected dot follows the map. When a host's dot size changes with the camera scale, the pinned dot of a `select`ed cell now takes the new size once the camera settles, instead of keeping the size it had when it was tapped.

[Compare `v0.10.1...v0.11.0` on GitHub](https://github.com/fndvit/VizVit-Map/compare/v0.10.1...v0.11.0)

## Added

- **`HoverOverlayHandle.restyle()`** re-runs the injected `computeStyle` for the selected cell and redraws its pinned dot in place: same node, no pop, no leaving trail. `select`'s rule still applies, so a cell that no longer draws a dot clears the selection. With nothing selected it does nothing.

## Fixed

- **The selected dot kept its tap-time size** while the map's dots were resized for a new camera scale. `<Globe>` now calls `restyle()` on every `stationary: true`, which is when a host rebakes scale-driven sizes.
