# Changelog

This package's changelog is **one page per version**, on the documentation site
under [`docs/changelog/`](./docs/changelog/index.md):

- **[All releases](./docs/changelog/index.md)** — the index, newest first
- **[Unreleased](./docs/changelog/unreleased.md)** — what is on `main` and not
  yet in a tagged version

This file stays at the root because that is where a reader looks for it — the
link from the README, GitHub's own `/CHANGELOG.md` convention, and any tool that
goes looking. It points rather than duplicating: a second copy of a document
edited every release is a copy that goes stale.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).
[CONTRIBUTING](./CONTRIBUTING.md#the-changelog-and-cutting-a-version) has the
release ritual.
