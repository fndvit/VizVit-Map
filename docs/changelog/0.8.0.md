# 0.8.0

_2026-10-05._ Focus. A globe can now say which one area it is about: `GlobeConfig.focus` names a region, the new `focus` capability outlines it, and every capability listed in `focus.confine` confines itself to it. The package's `markers` and `pins` honour it, and a host capability opts in the same way through `focusRegionFor` in its rule. So "the story's region" is declared once instead of being repeated as outlines, label regions and filters. `LayerHandle.setRegion` (0.7.0) gets its first consumer here. Nothing changes for an existing config.

[Compare `v0.7.0...v0.8.0` on GitHub](https://github.com/fndvit/VizVit-Map/compare/v0.7.0...v0.8.0)

## Added

- **The `focus` capability** (`GlobeConfig.focus`: `region`, `outline`, `visible`, `confine`), part of `DEFAULT_CAPABILITY_RULES`. It draws the region as a draped stroke layer that fades in and out like `outlines`. Layers are keyed by region id: a replaced region fades out but stays mounted, and a style change restyles the live layer. `outline: false` confines without drawing anything.
- **`focusRegionFor(config, name)`** (root and `…/capability`): the region for a capability that `confine` names, read in a rule's `select`, so capabilities stay independent of each other. **`createFocusRegionTracker(onShape)`** loads the shape once per region id and drops a superseded one.
- **`markers` and `pins` confine to the focus** when `confine` lists them. `markers` confines through `LayerHandle.setRegion`. `pins`, which is DOM-projected, filters the items it projects.

## Changed

- `outlines` and `focus` share one fading stroke-layer module. The outline behaviour is unchanged.
