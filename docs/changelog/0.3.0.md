# 0.3.0

_2026-09-22._ The hover tooltip's placement arithmetic moves out to
`@vit-foundation/ui`, where it is shared and tested. Nothing moves on screen.

**Upgrading:** this release adds a runtime dependency on
`@vit-foundation/ui` (>= 0.31.0), so it is MINOR rather than PATCH even though
no export changed — a caret range on `0.2.x` should not quietly start pulling in
another package.

[Compare against 0.2.1 on GitHub](https://github.com/fndvit/VizVit-Map/compare/v0.2.1...v0.3.0)

## Changed

- `<HoverTooltipOverlay>` positions its card with `anchor` from
  `@vit-foundation/ui/overlay` instead of a local `tooltipPos`. The placement is
  identical — the same offsets, paddings and card width go in — but the
  arithmetic now has a test suite and one other adapter, rather than being a
  copy that only ran inside a live layout.
- New dependency: `@vit-foundation/ui` (for the `./overlay` subpath).
