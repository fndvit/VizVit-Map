# 0.10.1

_2026-10-17._ No ghost fingers. On iOS Safari, after a while, a one-finger drag on the globe zoomed instead of panning. `touchNavigation: 'map'` now clears touches the view still believed were down.

[Compare `v0.10.0...v0.10.1` on GitHub](https://github.com/fndvit/VizVit-Map/compare/v0.10.0...v0.10.1)

## Fixed

- **A one-finger drag zoomed instead of panning** after a while on iOS Safari. A `SceneView` tracks fingers through pointer listeners on its own surface. When a finger's `pointerup` lands elsewhere or never arrives, the view keeps that finger, and every later one-finger drag is a pinch against it. With `touchNavigation: 'map'`, the ArcGIS adapter now watches the window and replays the missing ending to the surface as a `pointercancel`. It does this when a touch lifts off the surface, and, for any finger the browser forgot, when the next touch sequence starts.

## Added

- **`sweepStaleTouches(surface)`** in `…/arcgis`: the same clean-up for hosts that build their own view.
